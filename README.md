# Quick Sort

## Short description

Classify numbers correctly before the timer runs out.

## Description

Quick Sort is a fast, accessible, multilingual classification game for the browser. Players sort numbers according to a displayed threshold while the difficulty, timer, score, accuracy, and streak system keep each round challenging.

## Purpose

The extension is intended to exercise quick decision-making, numerical comparison, and concentration through short sessions available directly from the browser toolbar.
